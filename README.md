## 🛡️ Featured: Nitaq · نِطاق

**Your AI agent can be fooled. The scope can't.** An ISEF research project (advanced to the national round, 2026)
and an open-source tool that stops AI agents from acting on instructions hidden in what they read — e-mails,
web pages, skill files, tool descriptions — whether the order is written in Egyptian Arabic, Arabizi, English or
Base64. It judges every tool call by *where it goes and what it reads*, not by the language of the text.

- **Action guard** for Claude Code and Gemini CLI: MCP proxy, tool hook, policy (allowlist or taint).
- **Gateway**: an MCP server that puts the same guard between *cloud* AI (claude.ai, any MCP client) and your e-mail and files, with an approvals dashboard.
- **Desktop app** for Windows, macOS and Linux — no terminal needed — with a built-in AI agent (Gemini) that shows every blocked action.
- **Research benchmark**: 1,224 simulated attacks on a worst-case agent; attack success **100% → 33.3%** with Nitaq, with the remaining risk documented.
